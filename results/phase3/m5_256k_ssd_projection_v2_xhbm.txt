KEY INSIGHT:
- Naive rereads SSD KV every token -> seconds/token (unusable).
- XHBM keeps active KV in HBM; SSD only for idle conv. Active decode
  stays at base latency. SSD promote is one-time, hidden in typing pause.
- V-only quant shrinks KV so more context fits HBM before any offload.

HONEST DISCLOSURE:
- Amortization assumes promote overlaps typing window (deck v6.3 sec 5).
